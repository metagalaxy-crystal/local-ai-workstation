## 二、相关领域图谱

### 1. 光学与物理领域（核心）

```
┌─────────────────────────────────────────────────────┐
│                   光学与物理层                        │
│  波动光学 → 干涉/衍射理论 → 全息原理                  │
│  激光物理 → 光源技术 → 相干性控制                     │
│  量子光学 → 量子全息 → 量子信息存储                   │
└─────────────────────────────────────────────────────┘
```

**关键子领域：**
- 波动光学（Wave Optics）
- 激光物理（Laser Physics）
- 衍射理论（Diffraction Theory）
- 傅里叶光学（Fourier Optics）
- 量子光学（Quantum Optics）

### 2. 显示技术领域（应用核心）

```
┌─────────────────────────────────────────────────────┐
│                   显示技术层                          │
│  全息显示 ← 传统显示 → VR/AR/MR                      │
│  体显示 ← 光场显示 → 多视角显示                      │
│  裸眼3D ← 偏振3D → 光屏障3D                         │
└─────────────────────────────────────────────────────┘
```

**关键子领域：**
- 全息显示（Holographic Display）
- 光场显示（Light Field Display）
- 体渲染/体显示（Volumetric Display）
- 裸眼3D显示（Eyeglass-free 3D）
- 增强现实显示（AR Display）
- 近眼显示（Near-Eye Display）

### 3. 计算与人工智能领域（赋能层）

```
┌─────────────────────────────────────────────────────┐
│                   计算与AI层                          │
│  CGH算法 → 迭代傅里叶 → 相位恢复                     │
│  深度学习 → 全息生成网络 → 相位预测                    │
│  NeRF/3DGS → 神经渲染 → 实时全息重建                  │
└─────────────────────────────────────────────────────┘
```

**关键子领域：**
- 计算机生成全息（CGH）
- 相位恢复算法（Phase Retrieval）
- 深度学习全息（Deep Learning Holography）
- 神经辐射场（NeRF）
- 3D高斯溅射（3D Gaussian Splatting）
- 实时渲染（Real-time Rendering）

### 4. 材料与器件领域（硬件基础）

```
┌─────────────────────────────────────────────────────┐
│                   材料与器件层                        │
│  SLM → 液晶/微镜 → 刷新率/分辨率                     │

│  超表面 → 纳米结构 → 亚波长控制                       │

```

**关键子领域：**

- 衍射光学元件（DOE）
- 光折变材料（Photorefractive Materials）
