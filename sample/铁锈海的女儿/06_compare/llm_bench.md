### 质量评语

- **Qwen3.6-35B**：叙事完整度最高，6 镜头从蓝海回忆→父亲低语→时间转场→铁锈海现实→成人顿悟，镜头语言专业（特写/中景/远景/大远景），蒸汽朋克细节（铆钉皮围裙、黄铜齿轮腰带、煤灰颗粒）丰富。但耗时最久（188s）。
- **Trae GLM-5.2**：8 镜头最全面，含建立镜头和结尾呼应镜头，人物卡含年龄分段（7岁/29岁），英文 prompt 直供 Wan2.2 用。但部分镜头偏冗长。
- **Nanbeige4.2-3B**：蒸汽朋克细节最浓（锅炉虫外壳、铜壳机械蜻蜓、丝绸齿轮混搭），但人物卡缺失幼年玛莲（只画了 29 岁版），且推理模型生成 4458 token 耗时偏长。
- **DeepSeek-R1-8B**：人物理解准确（3 角色含年龄分段），中文描述流畅，但仅 4 镜头偏少，蒸汽朋克元素不足。推理 token 仅 150，思考最克制。
- **LFM2.5-8B-A1B**：把"铁锈海"误当成人名角色，人物理解严重错误；描述偏英文、偏简单。速度最快但质量最差。

## 4. 关键发现

1. **MoE 模型速度优势明显**：LFM2.5-8B-A1B 实际算量仅 1B，速度 201 tok/s 远超同尺寸 Dense 模型。
2. **推理模型（thinking）在 8GB VRAM 极慢**：Qwen35B think 模式超时 10min；Nanbeige 推理 4458 token 耗 88s。禁用 think 后 Qwen35B 降至 188s。
3. **CPU offload 是 35B 模型的瓶颈**：Qwen35B ngl=24（约 24/64 层在 GPU），prompt 处理阶段 6 tokens/s 极慢。
4. **小模型不一定快**：Nanbeige 3B 比 DeepSeek 8B 慢 4.8 倍，因推理模式生成大量思考 token。
5. **LFM2.5 中文理解弱**：把"铁锈海"当成人名，说明 MoE 小激活模型在中文细粒度理解上有缺陷。
6. **Qwen3.6-35B 质量最优但实用性差**：188s 单次调用对视频工作流（需多轮迭代）不现实。

## 5. 结论与推荐

| 场景 | 推荐模型 | 理由 |
|------|----------|------|
| 本地分镜（质量优先） | **Qwen3.6-35B-A3B (no-think)** | 质量最高，188s 可接受 |
| 本地分镜（速度优先） | **DeepSeek-R1-0528-Qwen3-8B** | 18s 出活，质量够用 |
| 在线对照基线 | **Trae GLM-5.2** | 28s 出 8 镜头，质量 4.8 |
| 不推荐 | LFM2.5-8B-A1B | 中文理解太弱 |

**最终定稿策略**：综合 Qwen35B/DeepSeek/GLM-5.2 三家之长，取 6 镜头定稿（见 `final_storyboard.json`）。

## 6. 云端 Strata 对照（2026-10-19）

> 测试环境：局域网主机（i7-14700 / 64GB RAM / RTX 3050 8GB / 模型在 NVMe SSD），
> Qwen3.8-Flash-Next（176B MoE，IQ2_XS），`reasoning_effort=low`，经 API 网关 :8082 访问，网络 RTT 约 6ms。
> 测试脚本：`06_compare\bench_strata.py`（与本地 bench 同一 prompt）。

| 模型 | 耗时 | completion tok | tok/s | JSON 合规 |
|------|------|---------------|-------|-----------|
| **云端 Strata (176B IQ2_XS)** | **42.0s** | 1707 | **40.6** | ✓ |
| LFM2.5-8B（本地） | 11.6s | 2336 | 201.0 | ✓ |
| DeepSeek-R1-8B（本地） | 18.5s | 1097 | 59.4 | ✓ |
| Qwen3.6-35B（本地） | 188.0s | 1133 | 6.0 | ✓ |

质量评分（沿用第 2 节标准）：人物理解 5 / 场景描述 5 / 镜头数 8 / 镜头描述质量 4.5 / 蒸汽朋克契合度 5 → **综合 4.8**

- 人物卡完整（玛莲 7 岁/29 岁双版本 + 父亲），场景含色温/光线方向，镜头描述含机位、景别、叠化转场与声音设计；扣分点：shot_008 黑场纯声音镜头对视频生成不可直接用。
- 速度探针（256 tok × 3 次中位）：31.3 tok/s，与部署文档记录的 ~28 tok/s 一致。

### 结论

| 维度 | 结论 |
|------|------|
| 质量 | 4.8，与 GLM-5.2 同档，接近本地最优 Qwen35B（5.0） |
| 速度 | 42s 出活，是本地 Qwen35B（188s）的 **4.5 倍**，质量几乎无损 |
| 性价比 | 0.114，本地 Qwen35B 仅 0.027；速度档 DeepSeek-R1-8B（0.195）质量低 1.2 分 |
| 网络开销 | 可忽略（RTT 6ms，耗时几乎全在生成） |
| 定位 | **质量档首选**：分镜定稿用 Strata；快速草稿仍用本地 DeepSeek-R1-8B（18s） |
| 附加收益 | LLM 阶段卸载到云端主机后，本机 8GB 显存可全部留给 ComfyUI（Z-Image/Wan2.2），无需为跑 LLM 停掉图像/视频管线；Strata 还支持图片识别，可用于 08_image_pipeline 的出图质检 |
