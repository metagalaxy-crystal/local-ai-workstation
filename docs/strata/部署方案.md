# Strata 部署方案（v3 最终版）

> 部署日期：2026-10-17
> 项目：Strata —— 本地大模型推理引擎（https://github.com/Niko1221/Strata / https://www.stratat.com）
> 部署位置：E:\strata

## 一、部署目标

在本机（Windows 11）部署 Strata 本地大模型引擎，实现：

1. 本地运行 Qwen3.8-Flash-Next 模型，数据不出本机
2. 对话支持多模态图片识别
3. 提供局域网服务，局域网内其他用户可通过 API 接入
4. 全部设置留档，便于后续查阅与维护

## 二、硬件配置核查结果

| 项目 | 本机配置 | Strata 要求 | 结论 |
|---|---|---|---|
| CPU | Intel i7-14700（20核28线程，AVX2 支持） | x86-64 + AVX2 | ✅ 达标 |
| 内存 | 63.6 GB | ≥32 GB（64GB 对应推荐量化档 IQ2_XS） | ✅ 达标 |
| 显卡 | NVIDIA RTX 3050 8GB（30 系） | RTX 20/30/40/50 系；≥12GB 理想，8GB 官方标注"能跑，但慢" | ⚠️ 可用，速度受限 |
| 显卡驱动 | 610.88 | ≥580 | ✅ 达标 |
| E 盘 | 4TB 机械硬盘（ST4000DM004），剩余约 1838 GB | 模型建议放 NVMe SSD | ⚠️ 故模型改放 C 盘 SSD |
| C 盘 | Kingston NVMe SSD 1TB，剩余约 657 GB | — | ✅ 模型存放地 |
| 操作系统 | Windows 11（build 26200） | Windows 10/11 | ✅ 达标 |
| Python | 3.13.7（已安装） | setup 会自动检测复用 | ✅ 无需另装 |
| git | 2.45.1 | 需要 | ✅ 已装 |
| 8080 端口 | 被系统程序 ApplicationWebServer（PID 8364）占用 | Strata 默认 8080 | ⚠️ 改用 8081 |

## 三、关键决策

| 决策项 | 选择 | 理由 |
|---|---|---|
| 模型版本 | qwen · IQ2_XS 量化 | 官方按 64GB 内存给出的推荐档；运行时约 35-55GB 权重载入内存 |
| 模型数据位置 | C:\Strata-data（NVMe SSD） | E 盘是机械硬盘，SSD 加载/推理明显更快；C 盘剩余 657GB 足够 |
| 多模态 | 开启，视觉编码器走 CPU（--vision cpu） | 8GB 显存吃紧，GPU 编码有 OOM 风险；CPU 方案稳定，功能完整 |
| 端口 | 8081 | 8080 已被占用 |
| 监听地址 | 0.0.0.0 + 强制 API key | 官方安全规则：无 key 严禁暴露服务 |
| API Key | `<your-api-key>` | 32 位随机生成 |
| 防火墙 | 放行入站 TCP 8081 | 局域网访问必需 |

## 四、执行命令（完整记录）

```powershell
# 1. 克隆仓库
git clone https://github.com/Niko1221/Strata.git E:\strata

# 2. 环境自检
cmd /c "E:\strata\START-HERE.bat" --check

# 3. 无人值守安装（模型约 70GB，可断点续传：中断后重跑同一命令即续传）
cmd /c "E:\strata\START-HERE.bat" --yes --family qwen --model IQ2_XS --data-dir C:\Strata-data --port 8081 --host 0.0.0.0 --api-key <your-api-key> --vision cpu --no-start

# 4. 防火墙放行（需管理员权限）
netsh advfirewall firewall add rule name="Strata Server 8081" dir=in action=allow protocol=TCP localport=8081

# 5. 启动服务（独立窗口，关闭窗口即停止服务）
Start-Process -FilePath "E:\strata\run-iq2_xs.bat"

# 6. 验证
curl http://127.0.0.1:8081/health
```

## 六、风险与预期

| 事项 | 说明 |
|---|---|
| 下载耗时 | 约 70GB；100Mbps 宽带约 1.5-2 小时；可中断续传 |
| 显存限制 | RTX 3050 8GB 走 GPU+CPU 混合推理，生成速度较慢（每秒几个 token 量级） |
| 首次加载 | 模型启动时电脑卡顿 1-3 分钟（大量数据进内存），属正常，不要关窗口 |
| Windows 已知问题 | 如遇 `cudaMalloc out of memory`（显存明明够），需把虚拟内存设为固定 65536 MB 后重启 |
| 并发 | 默认一次处理一个请求（后来者排队）；后续可用 `--parallel N` 开启并发解码 |
| 卸载 | 删除 E:\strata 和 C:\Strata-data 两个文件夹即彻底清除 |
| 网络 | 本机走 WLAN，局域网访问延迟/稳定性略逊有线；路由器如开 AP 隔离则局域网互访不可用 |
