## 二、日常操作

### 启动服务

```powershell
Start-Process -FilePath "E:\strata\run-iq2_xs.bat"
```

会弹出独立窗口；看到 `ready: http://127.0.0.1:8082/v1` 即就绪（首次启动需数分钟，之后 30-90 秒）。**关闭该窗口即停止服务。**

### 停止服务

直接关闭服务窗口；或：

```powershell
Stop-Process -Name "strata*" -Force   # 具体进程名以服务窗口/任务管理器为准
```

### 查看健康状态

```powershell
curl http://127.0.0.1:8081/health
```

返回 `{"status": "ok", ..., "loaded": true}` 表示模型已加载。

### 浏览器聊天（含图片识别）

- 本机：http://127.0.0.1:8081
- 局域网：http://<strata-host>:8082
- 页面含 Chat（对话，可拖入图片）、Monitor（实时监控）、About（设置）

## 五、安装命令原文（可重放/续传）

```powershell
# 实际执行命令（通过 .venv 直接调用 setup.py，因沙箱限制未用 START-HERE.bat）
& "E:\strata\.venv\Scripts\python.exe" E:\strata\setup.py --yes --family qwen --model IQ2_XS --port 8081 --host 0.0.0.0 --api-key <当时统一key，已于10-19作废> --vision cpu --no-start
```

- `--check` 只做环境自检；`--setup` 可对已装模型改配置或加装新模型

## 六、配置修改

### 修改任意设置（端口/上下文长度/并发/视觉等）

```powershell
# 直接调用 setup.py（推荐，避免 START-HERE.bat 的 cmd 嵌套问题）
& "E:\strata\.venv\Scripts\python.exe" E:\strata\setup.py --setup --context 65536      # 例：扩大上下文
& "E:\strata\.venv\Scripts\python.exe" E:\strata\setup.py --setup --parallel 2         # 例：开启 2 路并发解码
& "E:\strata\.venv\Scripts\python.exe" E:\strata\setup.py --setup --vision cpu         # 例：重新启用视觉
```

改完需重启服务（关闭服务窗口 → 重新运行 run-iq2_xs.bat）。

### 常用参数参考

| 参数 | 说明 |
|---|---|
| `--context N` | 上下文长度；8GB 显存默认 32768 |
| `--parallel N` | 并发解码路数（默认 1） |
| `--vision no\|cpu\|gpu` | 图片识别开关及所在设备 |
| `--port N` / `--host H` | 端口 / 监听地址 |
| `--api-key K` | API 密钥（暴露服务时必须配置） |
| `--family qwen\|swift\|coder\|unsloth` | 模型家族（coder 为代码特化版） |
| `--model ...` | 量化档位（IQ1_M / Q2_0 / IQ2_XS / IQ3_XXS / IQ3_S / UD-IQ4_XS 等） |

### 换更小的模型（内存/显存吃紧时）

```powershell
& "E:\strata\.venv\Scripts\python.exe" E:\strata\setup.py --setup --model Q2_0
```

### 升级 Strata

```powershell
& "E:\strata\.venv\Scripts\python.exe" E:\strata\setup.py --upgrade
```

## 七、IP 变动处理

本机当前局域网 IP 为 `<strata-host>`（WLAN）。若路由器重新分配了 IP：

1. 查新 IP：`ipconfig` → 找「无线局域网适配器 WLAN」的 IPv4 地址
2. 局域网用户把接入地址里的旧 IP 换成新 IP 即可，服务端无需任何改动
3. 建议在路由器里为本机做 DHCP 静态绑定，固定 IP 免维护

## 八、故障排查

| 症状 | 处理 |
|---|---|
| `the NVIDIA driver is too old` | 更新显卡驱动（NVIDIA App / nvidia.com）后重启，重跑安装命令 |
| 下载/安装中断 | 重跑同一安装命令，自动续传 |
| `port 8081 is already in use` | 服务已在运行（先查 /health），或 `--setup --port 8082` 换端口 |
| 非常慢、磁盘狂转、"engine stopped unexpectedly" | 内存不足：关闭大程序，或换更小量化档 `--setup --model Q2_0` |
| `ExpertCache: cudaMalloc(...) failed: out of memory`（显存明明够） | Windows 虚拟内存问题：把页面文件设为「自定义大小 · 初始 65536 MB · 最大 65536 MB」后重启 |
| `prompt ... exceeds the context` | `--setup --context 65536` 扩大上下文 |
| 局域网其他电脑访问不了 | ① 本机服务是否启动（/health）；② 防火墙规则是否在（见下）；③ 路由器是否开了 AP 隔离 |
| 防火墙规则丢失/重建 | 管理员 PowerShell 执行：`netsh advfirewall firewall add rule name="Strata Server 8081" dir=in action=allow protocol=TCP localport=8081` |
| 图片识别报错 | 确认 C:\Strata-data\models\mmproj-Qwen3.8-Flash-Next-BF16.gguf 存在；缺失时重跑安装命令自动续传；日志见 strata-iq2_xs.log |

仍无法解决：收集 `E:\strata\strata-*.log` 与安装输出，到 https://github.com/Niko1221/Strata/issues 提 issue。

## 九、安全须知

- 局域网访问全部经 API 网关（8082，每人一 key），**仅限可信网络使用**；不要把端口转发到公网
- 新增/吊销用户、更换 key：编辑 `gateway-keys.json` 后重启网关（详见 [API密钥管理方案.md](API密钥管理方案.md)）
- 彻底收回局域网访问：关闭网关窗口即可（Strata 本体已仅监听 127.0.0.1）
