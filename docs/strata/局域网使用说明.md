# Strata 局域网使用说明（发给使用者的版本）

> 更新日期：2026-10-19 ｜ 本文档面向局域网内的使用者，无需了解部署细节。

## 一、服务是什么

本局域网内的一台电脑运行着本地大模型 **Qwen3.8-Flash-Next**（Strata 引擎），提供：

- 中文/英文对话、写作、翻译、代码辅助
- **图片识别**（聊天中直接发图）
- OpenAI / Anthropic 兼容 API（可接入各种客户端和 IDE）

数据全部留在局域网内，不经过任何外部服务。

## 二、服务可用性

服务由管理员手动启动，**不是 24 小时在线**。使用前如遇连接失败，先联系管理员确认服务已启动。

管理员的启动顺序（供参考）：

1. `run-iq2_xs.bat` —— 加载模型，约 90 秒，窗口出现 `ready: http://127.0.0.1:8081/v1` 即就绪
2. `run-gateway.bat` —— API 网关，启动即就绪

## 三、接入信息

| 项目 | 值 |
|---|---|
| 地址 | `http://<strata-host>:8082` |
| API Key | 找管理员领取，**每人一个，不要外借** |
| 模型名 | `strata`（填任何名字都可以，服务端忽略） |

> 若地址打不开，可能是主机 IP 变了——找管理员确认新地址。

## 四、使用方式（按推荐排序）

### 1. 浏览器网页（最简单，支持发图片）

直接打开 **http://<strata-host>:8082** ，如页面要求鉴权就填入自己的 key。

- Chat 页：对话，可拖入图片提问
- Monitor 页：看服务实时状态
- 对话记录存在你自己浏览器里，清浏览器数据会消失

### 2. IDE 编程助手（Cursor / Trae）

```text
Base URL: http://<strata-host>:8082/v1
API Key:  你的key
Model:    strata
```

### 3. Python 脚本

```python
from openai import OpenAI

client = OpenAI(base_url="http://<strata-host>:8082/v1", api_key="你的key")
resp = client.chat.completions.create(
    model="strata",
    messages=[{"role": "user", "content": "你好"}],
    max_tokens=256,
)
print(resp.choices[0].message.content)
```

### 4. 命令行 curl

```bash
curl http://<strata-host>:8082/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的key" \
  -d '{"model":"strata","messages":[{"role":"user","content":"你好"}],"max_tokens":64}'
```

### 5. Claude Code（Anthropic 兼容）

```powershell
$env:ANTHROPIC_BASE_URL   = "http://<strata-host>:8082"
$env:ANTHROPIC_AUTH_TOKEN = "你的key"
$env:ANTHROPIC_MODEL      = "claude-sonnet-4-20250514"  # 名字随意
```

## 五、使用须知

| 事项 | 说明 |
|---|---|
| 速度 | 约 28 token/秒（8GB 显卡量级，比普通网页 AI 慢属正常） |
| 排队 | 服务一次只处理一个请求，别人在用你会排队，响应慢不一定是坏了 |
| 上下文 | 单次对话最多约 32768 token（约 2 万汉字），太长会报错，重开新对话即可 |
| 思考力度 | 可在请求里加 `"reasoning_effort": "none/low/medium/high"`，简单问题用 low 更快 |
| 用量 | 管理员能看到每个 key 的 token 用量（不含对话内容），请合理使用 |
| key 安全 | 泄露立即告诉管理员吊销，会发新 key |

## 六、常见问题

| 问题 | 办法 |
|---|---|
| 401 错误 | key 没填/填错，检查有没有多复制空格 |
| 连接超时/拒绝 | 服务没开，联系管理员 |
| 回复特别慢 | 别人在用（排队中），或你的上下文太长了 |
| 图片识别没反应 | 确认图片已上传成功（消息里有缩略图）再发送 |
