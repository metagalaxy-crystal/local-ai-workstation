
问题是：鸡兔同笼，共有 35 个头，94 条腿。问鸡和兔各有多少只？我需要给出计算过程。

首先，理解问题：鸡和兔在一个笼子里，总共有 35 个头和 94 条腿。我需要找出鸡和兔各有多少只。

回想一下，鸡有 2 条腿，兔有 4 条腿。每个动物都有一个头，所以头的总数就是动物的总数。

设鸡的数量为 C，兔的数量为 R。

根据头数，C + R = 35。

根据腿数，鸡的腿数是 2C，兔的腿数是 4R，总腿数是 2C + 4R = 94。

所以，我有两个方程：

1) C + R = 35

2) 2C + 4R = 94

我需要解这个方程组，找到 C 和 R 的值。

我可以简化第二个方程。2C + 4R = 94，除以 2：C + 2R = 47。

现在我有：

1) C + R = 35

2) C + 2R = 47

减去第一个方程从第二个方程：(C + 2R) - (C + R) = 47 - 35

这得到 C + 2R - C - R = 12，所以 R = 12。

兔子的数量是 12。

现在，从第一个方程，C + R = 35，所以 C + 12 = 35，因此 C = 35 - 12 = 23。

所以，鸡有 23 只，兔有 12 只。

现在，检查腿数：鸡 23 只，腿数 23 * 2 = 46。

兔 12 只，腿数 12 * 4 = 48。

总腿数 46 + 48 = 94。完美。

头数：23 + 12 = 35，也正确。

我可以用另一种方法验证。假设所有动物都是鸡，那么 35 只鸡有 70 条腿，但实际有 94 条，所以多出的腿是兔子的。

兔子比鸡多 2 条腿（因为鸡 2，兔 4），所以多出的腿数除以 2 就是兔子的数量。

总多出腿数：94 - 70 = 24。

每只兔子多 2 条腿，所以兔子数量是 24 / 2 = 12。

然后鸡是 35 - 12 = 23。同样的答案。

如果假设所有都是兔子：35 只兔子有 140 条腿，但实际只有 94，所以少算了腿数。

每只兔子比鸡多 2 条腿，但这里是从兔子假设，所以总腿数多算了 140 - 94 = 46 条腿。

由于每只兔子有 4 腿，每只鸡有 2 腿，所以如果减少一只兔子，增加一只鸡，腿数减少 2 条。
