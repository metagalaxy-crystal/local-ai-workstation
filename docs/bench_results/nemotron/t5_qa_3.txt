在 HTTP 协议中，404 状态码表示 **“资源未找到”（Not Found）**。  
具体含义如下：

| 状态码 | 类别 | 含义 |
|--------|------|------|
| **404** | 客户端错误（4xx） | 服务器成功接收请求，但无法在服务器上找到指定的资源（页面、文件、接口等）。这通常是因为 URL 拼写错误、资源已被删除或移动、或是请求的路径不存在。 |

### 常见场景
- 用户输入了错误的网址（如 `http://example.com/nonexistent-page`）。
- 网站结构改动，原来的链接失效。
- 服务器配置错误，导致请求的资源根目录不存在。
- API 请求的资源 ID 不存在或已被删除。

### 与 403、410 的区别
- **403 Forbidden**：客户端有权访问，但服务器拒绝响应（权限不足）。
- **410 Gone**：资源已永久删除，且不会再恢复，通常用于告诉客户端该资源不再可用。

### 处理建议
1. **检查 URL**：确认地址是否拼写正确、是否包含必要的路径和查询参数。  
2. **查看日志**：服务器端日志可以帮助确认请求到底在哪一步被拒绝。  
3. **返回友好页面**：在生产环境中，通常会为 404 页面提供导航、搜索框或返回首页的链接，提升用户体验。  

总之，404 表示“请求的资源不存在”，是一种客户端错误，需要前端或后端根据具体业务场景进行相应的处理和提示。
