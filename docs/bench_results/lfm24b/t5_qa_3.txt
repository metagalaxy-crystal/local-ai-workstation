HTTP 协议中的 **404 状态码**表示：

> **“未找到（Not Found）”**

### 具体含义：
- 服务器收到客户端的请求，但没有找到与请求路径匹配的资源。
- 通常说明客户端请求的资源不存在（例如：网页、图片、API 接口等）。

---

### 常见原因：
- 用户输入了错误的 URL。
- 页面已经被删除或移动，但未更新重定向。
- API 接口返回 404 表示请求的资源不存在。

---

### HTTP 状态码分类简述：
HTTP 状态码分为几大类：
- **1xx**：信息响应（如 100 持续）
- **2xx**：成功（如 200 OK）
- **3xx**：重定向（如 301 永久重定向）
- **4xx**：客户端错误（如 404 Not Found，400 Bad Request）
- **5xx**：服务器错误（如 500 Internal Server Error）

---

### 示例：
当你在浏览器中输入 `https://example.com/nonexistentpage`，如果该页面不存在，服务器可能会返回：
```
HTTP/1.1 404 Not Found
```

---

### 应对建议：
- 检查 URL 是否拼写正确。
- 如果是网站访问失败，联系网站管理员。
- 对于 API 调用失败，检查请求的路径或资源是否存在。
