在 HTTP 协议中，**404 状态码**表示 **“Not Found”（未找到）**。

### 详细解释：
- **含义**：当客户端（如浏览器）向服务器请求某个资源（URL、文件、API 接口等），但服务器无法找到与之对应的资源时，会返回 404 状态码。
- **常见场景**：
  - 请求的 URL 路径错误（拼写错误、路径不存在）。
  - 资源已被删除、移动或迁移到新的路径。
  - 服务器配置错误（如路由规则未正确设置）。
  - 跨域请求中目标资源不存在。
- **与 200 的对比**：200 表示请求成功，资源已找到并返回内容；404 则明确告知“该资源在当前位置不可用”。

### 补充说明：
- **标准依据**：根据 HTTP/1.1 规范（RFC 7231），404 是标准状态码之一，用于指示客户端请求的资源未找到。
- **实际应用**：前端开发或调试时，404 是常见问题信号。开发者需检查 URL、文件路径、服务器日志等定位问题。
- **关联概念**：404 与 **403（Forbidden，禁止访问）** 不同——404 是“找不到”，403 是“找到但权限不足”。

### 示例：
```http
HTTP/1.1 404 Not Found
Content-Type: text/html

<html>
  <body>
    <h1>404 Page</h1>
    <p>The requested resource could not be found.</p>
  </body>
</html>
```

总结：**404 状态码是 HTTP 协议中明确标识“请求的资源未被服务器找到”的关键信号**，对调试、开发及理解网络请求流程至关重要。
