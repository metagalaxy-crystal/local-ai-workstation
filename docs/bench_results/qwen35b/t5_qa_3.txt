在 HTTP 协议中，**404 状态码**表示 **“Not Found”（未找到）**。

### 具体含义：
当客户端（如浏览器）向服务器请求一个资源（如网页、图片、API 接口等）时，服务器**无法找到**该资源，就会返回 404 状态码。

### 常见原因：
1. **URL 拼写错误**：地址栏输入的网址有误。
2. **资源已被删除或移动**：原链接指向的内容已被管理员删除，或移动到新的位置而未做重定向。
3. **链接失效**：其他网站引用的旧链接（死链）。
4. **服务器配置问题**：如路由未正确配置，导致请求无法匹配到对应的处理程序。

### 对用户体验的影响：
- 用户通常会看到“404 页面未找到”的错误页面。
- 良好的 404 页面应提供导航建议，帮助用户找到所需内容，减少跳出率。

### 技术提示：
- 404 属于 **4xx 客户端错误** 类别，表示请求本身有误，服务器无法处理。
- 与 **500 错误**（服务器内部错误）不同，404 通常不是服务器故障，而是请求的资源不存在。

### 示例：
```http
HTTP/1.1 404 Not Found
Content-Type: text/html
Content-Length: 137

<html>
<body>
<h1>404 Not Found</h1>
<p>The requested URL was not found on this server.</p>
</body>
</html>
```

总之，404 是 Web 开发中最常见的状态码之一，主要用于告知用户“你找的东西不存在”。
