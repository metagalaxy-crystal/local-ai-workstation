在 HTTP 协议中，**404** 状态码表示 **"Not Found"（未找到）**。

具体含义如下：

- **客户端请求的资源在服务器上不存在**。
- 服务器已经理解了请求，但无法找到请求的资源（例如网页、图片、API 端点等）。
- 这通常是一个**客户端错误**（4xx 系列），意味着问题出在请求本身（如 URL 拼写错误、链接失效、资源被删除等），而非服务器端故障。

### 常见触发场景：
- 用户访问了一个不存在的网页 URL。
- 链接指向的资源已被删除或移动。
- API 请求了一个不存在的接口路径。
- 缓存中的旧链接失效。

### 与其他状态码的区别：
- **401 Unauthorized**：需要身份验证。
- **403 Forbidden**：服务器理解请求但拒绝执行（权限不足）。
- **500 Internal Server Error**：服务器内部错误，与客户端请求无关。

### 建议处理方式：
- 检查 URL 是否正确。
- 确认资源是否已被删除或移动（如有移动，应使用 301/302 重定向）。
- 对于网站开发者，可提供友好的自定义 404 页面以提升用户体验。
