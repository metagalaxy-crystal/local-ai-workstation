
我们使用双向链表和字典来实现LRUCache。
 双向链表用于维护最近最少使用的顺序，字典用于快速查找。
 我们定义一个节点类，每个节点包含key, value, prev和next。
 然后，我们创建一个LRUCache类，包含：
   - capacity: 容量
   - cache: 字典，用于存储键值对
   - head: 链表头节点，用于快速定位最近最常用的节点
   - tail: 链表尾节点，用于快速定位最近最少用的节点

 注意：当插入新数据时，如果已存在则更新并移动到最近最常用的位置，否则插入到头节点位置。
 当删除节点时，从链表中删除，并从字典中删除。

 我们使用双向链表，这样可以在O(1)时间内删除任意节点，并调整顺序。

 步骤：
  1. 初始化：设置容量，空字典，头尾节点。
  2. 在put方法中，如果key存在，则更新其值，并将其移动到最近最常用的位置（即从原位置删除，然后插入到头节点位置）。
     如果key不存在，则创建新节点，插入到头节点位置，并更新字典。
     如果缓存已满，则删除尾节点（最近最少用）并更新字典，然后插入新节点。

 注意：我们维护一个双向链表，最近最常用的是head，最近最少用的是tail。

 但是，我们通常使用一个双向链表，并且维护一个最近最少使用的节点（tail）和最近使用的节点（head）。

  class Node:
      __slots__ = ('key', 'value', 'prev', 'next')
      def __init__(self, key, value):
          self.key = key
          self.value = value
          self.prev = None
          self.next = None

  class LRUCache:

      def __init__(self, capacity: int):
          self.capacity = capacity
          self.cache = {}
          self.head = Node(None, None)
          self.tail = Node(None, None)
          self.head.next = self.tail
          self.tail.prev = self.head

      def get(self, key: int) -> int:
          if key not in self.cache:
              return -1
          node = self.cache[key]
