在 HTTP 协议中，**404 状态码表示“Not Found”（未找到）**。

### 详细解释：
- **含义**：当客户端（如浏览器）向服务器请求一个特定的资源（如 URL、文件、API 接口等），但服务器无法找到该资源时，会返回 `404 Not Found` 状态码。
- **常见场景**：
  - URL 路径错误（拼写错误、路径不存在）。
  - 资源已被删除、移动或删除。
  - 服务器配置问题导致无法访问该资源。
  - 跨域请求或权限问题导致资源不可见（但通常权限问题返回 401/403，404 更侧重“资源不存在”）。

### 补充说明：
- **与 200 的区别**：`200 OK` 表示请求成功，资源已找到并返回内容；`404` 明确表示“未找到”。
- **开发者作用**：开发者可通过 404 状态码快速定位问题（如检查链接、资源路径或服务器配置）。前端可自定义 404 页面（如提示“页面不存在”），提升用户体验。
- **注意事项**：404 是标准 HTTP 状态码，适用于所有基于 HTTP 的场景（Web、API、移动端等）。某些框架（如 Spring、Django）可能将 404 与业务逻辑结合处理。

### 示例：
```http
HTTP/1.1 404 Not Found
Content-Type: text/html

<html>
  <body>
    <h1>404 Not Found</h1>
    <p>The requested resource could not be found.</p>
  </body>
</html>
```

简言之，**404 是 HTTP 协议中明确的“资源未找到”信号**，是调试和诊断请求问题的关键指标之一。
