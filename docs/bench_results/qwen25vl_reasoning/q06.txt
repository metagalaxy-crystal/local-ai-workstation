首先，我们来分析代码的执行过程和输出结果。

1. 函数定义：
   ```python
   def f(a=[]):
       a.append(len(a))
       return a
   ```
   这个函数接受一个列表 `a` 作为参数。如果 `a` 为空列表（即 `a = []`），则默认使用空列表作为参数。如果 `a` 不为空，则使用传入的列表。

2. 第一次调用 `f()`：
   ```python
   print(f())
   ```
   - 第一次调用时，`a` 为默认的空列表 `[]`。
   - `a.append(len(a))` 会将列表长度（0）添加到列表中，因此列表变为 `[0]`。
   - 返回值为 `[0]`。
   - 打印结果：`[0]`

3. 第二次调用 `f()`：
   ```python
   print(f())
   ```
   - 第二次调用时，`a` 为 `[0]`。
   - `a.append(len(a))` 会将列表长度（1）添加到列表中，因此列表变为 `[0, 1]`。
   - 返回值为 `[0, 1]`。
   - 打印结果：`[0, 1]`

4. 第三次调用 `f([7])`：
   ```python
   print(f([7]))
   ```
   - 第三次调用时，`a` 为 `[7]`。
   - `a.append(len(a))` 会将列表长度（1）添加到列表中，因此列表变为 `[7, 1]`。
   - 返回值为 `[7, 1]`。
   - 打印结果：`[7, 1]`

最终答案：
```
[0]
[0, 1]
[7, 1]
```
