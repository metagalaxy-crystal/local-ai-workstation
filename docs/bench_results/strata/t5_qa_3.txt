# HTTP 404 状态码

**404 Not Found**（未找到）表示服务器无法找到请求的资源。

## 含义

当客户端（如浏览器）请求一个 URL，而服务器在对应路径下找不到该资源时，就会返回 404 状态码。

## 常见场景

- 访问了一个不存在的网页或文件
- URL 拼写错误（如大小写、路径错误）
- 资源已被删除或移动
- 链接已失效（死链）

## 示例

```
GET /images/logo.png HTTP/1.1
Host: example.com

HTTP/1.1 404 Not Found
Content-Type: text/html

<html><body><h1>404 - Page Not Found</h1></body></html>
```

## 分类

404 属于 **4xx 客户端错误**类别，即错误源于客户端的请求（URL 不正确），而非服务器自身的问题。

## 与相关状态码的区别

| 状态码 | 含义 |
|--------|------|
| **404** | 资源不存在 |
| **403** | 资源存在，但客户端无权访问 |
| **405** | 资源存在，但请求方法不被允许 |
| **500** | 服务器内部错误 |

> 💡 很多网站会自定义 404 页面（如 GitHub、Twitch 等），以提供导航链接或趣味内容来改善用户体验。
