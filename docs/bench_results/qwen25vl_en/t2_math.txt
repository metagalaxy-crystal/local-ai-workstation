To determine the number of chickens and rabbits, we can set up a system of linear equations based on the given information.

Let:
- \( x \) be the number of chickens,
- \( y \) be the number of rabbits.

We know the following:
1. Each chicken and each rabbit has one head, so the total number of heads is given by:
   \[
   x + y = 35
   \]
2. Each chicken has 2 legs and each rabbit has 4 legs, so the total number of legs is given by:
   \[
   2x + 4y = 94
   \]

We now have the following system of equations:
1. \( x + y = 35 \)
2. \( 2x + 4y = 94 \)

First, we can simplify the second equation by dividing all terms by 2:
\[
x + 2y = 47
\]

Now we have the simplified system:
1. \( x + y = 35 \)
2. \( x + 2y = 47 \)

To eliminate \( x \), we subtract the first equation from the second:
\[
(x + 2y) - (x + y) = 47 - 35
\]
\[
x + 2y - x - y = 12
\]
\[
y = 12
\]

Now that we have \( y = 12 \), we substitute this value back into the first equation to find \( x \):
\[
x + 12 = 35
\]
\[
x = 35 - 12
\]
\[
x = 23
\]

So, the number of chickens is 23 and the number of rabbits is 12. To verify, we check the total number of heads and legs:
- Total heads: \( 23 + 12 = 35 \)
- Total legs: \( 2 \times 23 + 4 \times 12 = 46 + 48 = 94 \)

The calculations confirm that the solution is correct. Therefore, the number of chickens is \(\boxed{23}\) and the number of rabbits is \(\boxed{12}\).
