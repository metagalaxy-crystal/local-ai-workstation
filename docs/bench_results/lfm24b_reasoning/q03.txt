**推理过程如下：**

1. 已知 A 在 B 之前到达 → A < B  
2. 已知 C 在 D 之后、E 之前到达 → D < C < E  
3. 已知 B 在 D 之前到达 → B < D  
4. 已知 E 不是第一名。

结合这些信息：

- 从（1）和（3），我们有 A < B < D  
- 从（2），我们有 D < C < E  
- 综合以上，得到：A < B < D < C < E  
- 但是根据（2），C 必须在 E 之前，所以顺序应为：A < B < D < C < E  
- 检查 E 是否为第一名：E 是最后一名，符合“E 不是第一名”的条件。

因此，完整的名次顺序为：A、B、D、C、E。

**最终答案：**  
A、B、D、C、E
