**推理过程**：

1. **函数定义与默认参数**  
   函数 `f(a=[])` 使用了默认参数 `a=[]`。在 Python 中，默认参数是**函数定义时一次性创建的**，这意味着所有后续调用若未传入参数时，都会使用同一个列表对象。

2. **第一次调用 `print(f())`**  
   - 首次调用 `f()` 时，`a` 是默认的空列表 `[]`。  
   - 执行 `a.append(len(a))`，此时 `len(a)` 为 `0`，所以列表变为 `[0]`。  
   - 返回值 `[0]` 被打印。

3. **第二次调用 `print(f())`**  
   - 由于 `a` 是同一个默认列表对象，此时 `a` 已经是 `[0]`。  
   - 执行 `a.append(len(a))`，`len(a)` 为 `1`，列表变为 `[0, 1]`。  
   - 返回值 `[0, 1]` 被打印。

4. **第三次调用 `print(f([7]))`**  
   - 此时传入参数 `[7]`，函数使用这个新列表而非默认参数。  
   - 执行 `a.append(len(a))`，`len(a)` 为 `1`（列表 `[7]` 长度为 1），列表变为 `[7, 1]`。  
   - 返回值 `[7, 1]` 被打印。

**最终输出**：
```
[0]
[0, 1]
[7, 1]
```
**答案**：  
第一行：`[0]`  
第二行：`[0, 1]`  
第三行：`[7, 1]`
