
问题是：鸡兔同笼，共有 35 个头，94 条腿。问鸡和兔各有多少只？需要给出计算过程。

首先，我理解这是一个经典的鸡兔同笼问题。鸡有2条腿，兔有4条腿。总共有35个头和94条腿。我需要找出鸡和兔子的数量。

让我定义变量：设鸡的数量为C，兔子的数量为R。

因为每个动物都有一个头，所以头数的总和是鸡和兔子的数量之和。因此，C + R = 35。

对于腿数，鸡有2条腿，兔子有4条腿。所以总腿数是2C + 4R = 94。

现在我有两个方程：

1. C + R = 35

2. 2C + 4R = 94

我需要解决这个方程组来找到C和R。

我可以简化第二个方程。2C + 4R = 94，可以除以2，得到C + 2R = 47。

所以现在方程是：

1. C + R = 35

2. C + 2R = 47

减去第一个方程从第二个方程中，以消除C。

所以，(C + 2R) - (C + R) = 47 - 35

这给出C + 2R - C - R = 12

所以R = 12

兔子的数量是12。

现在，从第一个方程，C + R = 35，代入R=12，C + 12 = 35，所以C = 35 - 12 = 23。

所以鸡有23只，兔子有12只。

现在检查腿数：鸡23只，每只2条腿，所以23*2=46条腿。

兔子12只，每只4条腿，所以12*4=48条腿。

总腿数46 + 48 = 94，对。

头数23 + 12 = 35，也对。

完美。

另一个方法是假设所有动物都是鸡，然后调整。

如果所有35只都是鸡，那么腿数应该是35*2=70条腿，但实际是94条，所以多了94-70=24条腿。

每只兔子比鸡多2条腿，所以多出的腿是因为有兔子。

每只兔子多2条腿，所以兔子数量是24 / 2 = 12。

然后鸡是35 - 12 = 23。
