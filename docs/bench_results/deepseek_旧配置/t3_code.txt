
我们需要计算每个数字的出现频率，然后按频率从高到低排序（频率相同按数值升序），最后返回前k个数字。
 步骤：
 1. 使用字典（或Counter）来统计每个数字出现的频率。
 2. 将字典的键值对转换成列表，然后根据频率降序，如果频率相同则根据数值升序排序。
 3. 取前k个元素，然后提取出这些数字（可能重复，但这里每个数字只出现一次，所以按频率排序后每个数字只出现一次，除非有多个相同频率且相同的数字，但题目按频率从高到低排序，频率相同按数值升序，所以相同的数字只取一次，但如果有多个相同数字呢？注意：题目要求是出现频率最高的k个数，如果频率相同，按数值升序，所以如果有多个数字频率相同，我们按数值排序后取靠前的，但这里k个数，所以如果频率相同，我们按数值升序排序，然后从这些频率相同的数字中按升序取，直到达到k个。

 但是注意：题目要求是返回出现频率最高的k个数，并且按频率从高到也排序，频率相同按数值升序。

 我们可以这样做：
 - 统计频率，得到一个字典。
 - 将字典的每个元素转换为元组，然后根据元组的第一个元素（频率）降序，第二个元素（数字）升序排序。
 - 然后取前k个元组，将数字提取出来。

 注意：如果k为0，则返回空列表。
 注意：如果列表中有多个数字，我们需要确保在频率相同的情况下按数字升序排序，然后取前k个。

 但是，如果k大于不同数字的个数呢？例如，列表中有5个不同的数字，但k=10，那么我们只返回5个数字，但按照题目要求，我们只返回频率最高的k个数，如果k大于所有不同的数字个数，那么我们就返回所有数字。

 实现：
 我们可以使用collections.Counter来统计频率。
 然后使用sorted函数，参数：key为负频率（这样降序）或者反过来，我们可以用lambda来指定排序键，第一个是负频率（为了降序，因为频率大的我们希望在前），第二个是数字（正序，因为数字小的在前）。但是注意，题目要求频率从高到低，所以我们可以用：
 sorted_list = sorted(freq.items(), key=lambda x: (-x[1], x[0]))

 然后取前k个。

 但是，注意题目要求：按频率从高到低排序，频率相同按数值升序。
 所以排序规则是：首先按频率降序，频率相同时按数值升序。

 我们使用：
   sorted_freq = sorted(freq.items(), key=lambda x: (-x[1], x[0]))

 然后取前k个，再从元组中提取数字。

 注意：如果k为0，返回空列表。另外，如果k很大，比如比总的不同数字种类还多，那么我们就返回所有数字。

 我们也可以使用heapq，但这里用排序更简单。

 步骤：
 1. 导入Counter。
 2. 统计频率。
 3. 转换为列表并排序。
 4. 取前k个，然后提取数字。

 注意：题目要求返回的是整数列表，所以结果应该是一个列表。

 但是，如果k为0，我们返回[]。
 如果k为负数，我们也可以处理，但题目未说明，通常k是非负整数，所以我们假设k非负。

 另外，注意：如果k大于等于所有不同数字的个数，那么我们返回所有数字（按频率排序，如果频率相同按数值排序）。

 我们可以这样：
   sorted_freq = sorted(freq.items(), key=lambda x: (-x[1], x[0]))
   top = sorted_freq[:k]

 然后从top中提取数字，即[ num for count, num in top ]。

 但是，如果k为0，我们返回空列表，这样也可以。
