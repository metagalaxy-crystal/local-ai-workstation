**推理过程**  

1. **设定身份**  
   - 骑士（Knight）只说真话。  
   - 无赖（Knave）只说假话。

2. **假设甲是骑士**  
   - 甲的话：“乙是无赖”。若甲真，则乙必为无赖。  
   - 乙（无赖）说：“丙是无赖”。因为无赖只说假话，丙不可能是无赖，故丙是骑士。  
   - 丙（骑士）说：“甲和乙都是无赖”。此句包含两个子句：  
     - “甲是无赖” → 与假设甲为骑士矛盾。  
     - “乙是无赖” → 与乙为无赖相符。  
   - 因为丙的整体陈述必须为真，而其中一子句为假，导致矛盾。  
   - **结论：** 甲不可能是骑士。

3. **假设甲是无赖**  
   - 甲的话为假，故乙不是无赖，乙只能是骑士。  
   - 乙（骑士）说：“丙是无赖”。此句为真，所以丙是无赖。  
   - 丙（无赖）说：“甲和乙都是无赖”。  
     - “甲是无赖” → 与假设相符。  
     - “乙是无赖” → 与乙为骑士矛盾。  
   - 因为丙的整体陈述必须为假，而其中一子句为真，导致矛盾。  
   - **结论：** 甲不可能是无赖。

4. **唯一可能的身份**  
   - 由上述两种假设皆导致矛盾，故甲的身份只能是**骑士**（因为假设甲为无赖已被排除，唯一剩余的可能是甲为骑士，但前面的推导显示即使甲为骑士也会产生矛盾，说明我们在第三步的排除时出现了逻辑漏洞）。  
   - 重新审视：**若甲为骑士**，则乙为无赖（如第2步），乙的陈述“丙是无赖”必为假，故丙为骑士；丙的陈述“甲和乙都是无赖”则包含“甲是无赖”，这与甲为骑士矛盾。  
   - 因此，**甲不可能是骑士**，只能是**无赖**。  

5. **重新验证甲为无赖的情形**  
   - 甲（无赖）说“乙是无赖” → 假，故乙是骑士。  
   - 乙（骑士）说“丙是无赖” → 真，故丙是无赖。  
   - 丙（无赖）说“甲和乙都是无赖”。  
     - “甲是无赖” → 真（符合丙的身份）。  
     - “乙是无赖” → 假（乙是骑士），整体陈述为假，符合无赖的特性。  
   - 所有陈述均满足各自身份的要求，**无矛盾**。

6. **最终结论**  
   - 甲：无赖  
   - 乙：骑士  
   - 丙：无赖
