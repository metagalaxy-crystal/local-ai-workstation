**推理过程**  

1. **已知条件**  
   - A 在 B 之前到达 → A < B  
   - C 在 D 之后、E 之前到达 → D < C < E  
   - B 在 D 之前到达 → B < D  
   - E 不是第一名 → 至少有一个人在 E 前面  

2. **由 B < D 与 D < C 得到**  
   - B < D < C，所以顺序已有 **B < D < C**。  

3. **把 A 放入**  
   - 已知 A < B，故 **A < B < D < C**。  

4. **把 E 放入**  
   - 条件 D < C < E，说明 **C < E**。  
   - 结合已有顺序 **B < D < C**，得到 **B < D < C < E**。  
   - 因为 E 不是第一名，且已经有 A、B、D 在 E 前面，满足此条件。  

5. **检查是否还有位置空缺**  
   - 目前的顺序是 **A < B < D < C < E**，正好是 5 个人的完整排列，所有条件都已满足。  

**最终答案**  

A、B、D、C、E
