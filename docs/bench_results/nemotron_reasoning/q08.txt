**推理过程**

1. **已知条件**  
   - 平面上有 5 条直线。  
   - 任意两条直线相交（即没有平行的直线）。  
   - 任意三条直线不共点（即没有三条直线经过同一点）。

2. **每条新直线增加的区域数**  
   当在已经画好的直线中加入一条新直线时，这条直线会与已有的直线相交，产生若干交点。  
   - 若这条直线与已有的 \(k\) 条直线相交，则会产生 \(k\) 个交点，把这条直线划分成 \(k+1\) 段。  
   - 每一段都会把原有的一个区域分成两个，所以新直线最多增加的区域数等于它被分成的段数，即 \(k+1\)。

3. **递推计算**  
   - 初始时没有直线，平面只有 1 个区域。  
   - 第 1 条直线与已有 0 条直线相交，增加 \(0+1 = 1\) 条区域 → 总区域数 \(1+1 = 2\)。  
   - 第 2 条直线与已有 1 条直线相交，增加 \(1+1 = 2\) 条区域 → 总区域数 \(2+2 = 4\)。  
   - 第 3 条直线与已有 2 条直线相交，增加 \(2+1 = 3\) 条区域 → 总区域数 \(4+3 = 7\)。  
   - 第 4 条直线与已有 3 条直线相交，增加 \(3+1 = 4\) 条区域 → 总区域数 \(7+4 = 11\)。  
   - 第 5 条直线与已有 4 条直线相交，增加 \(4+1 = 5\) 条区域 → 总区域数 \(11+5 = 16\)。

4. **通项公式**  
   以上过程可写成公式：  
   \[
   R_n = R_{n-1} + n \quad (R_0 = 1)
   \]
   解得  
   \[
   R_n = 1 + \frac{n(n+1)}{2}
   \]
   代入 \(n=5\)：  
   \[
   R_5 = 1 + \frac{5 \times 6}{2} = 1 + 15 = 16
   \]

**结论**  
这 5 条直线最多能把平面分成 **16** 个区域。

**最终答案**  
16
