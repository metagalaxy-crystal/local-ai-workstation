**推理过程**

1. **初始状态**：左岸有 【农夫、狼、羊、白菜】，右岸空。  
2. **限制条件**：  
   - 狼和羊单独在一起会吃羊。  
   - 羊和白菜单独在一起会被吃。  
   - 农夫必须在船上，船一次只能带 **农夫 + 同一种东西**（狼、羊或白菜）。  

3. **设定可行状态**：一个状态在左/右岸的动物组合中，只要不出现 “狼+羊” 或 “羊+白菜” 且 **没有农夫** 时即为安全。

4. **最少单程数的下界**  
   - 为了把 **狼**、**羊**、**白菜** 三样物品全部从左岸移到右岸，至少需要把它们各自运一次，即 **3 个单程**（每样东西一次）。  
   - 但因为 **羊** 必须在农夫的看守下才能安全搬运，且在一次运送中只能带 **一种** 东西，还必须 **返回** 把农夫带回左岸（否则下一步的运送会出现非法组合），所以实际的往返次数会比 3 多。  

5. **尝试构造最短路径**  

   - **第1次**（左→右）：农夫带 **羊** 过河。  
     - 左岸：【农夫、狼、白菜】（安全，因为没有羊）  
     - 右岸：【羊】  

   - **第2次**（右→左）：农夫 **单独** 返回。  
     - 右岸：【羊】（安全）  
     - 左岸：【农夫、狼、白菜】  

   - **第3次**（左→右）：农夫带 **狼** 过河。  
     - 左岸：【白菜】（安全，因为没有羊）  
     - 右岸：【羊、狼】 → **不安全**（狼会吃羊），所以此安排不行。  

   - **改进**：在第3次之前，必须先把 **羊** 从右岸调回左岸，以免狼与羊在同一岸出现。  

   - **重新安排**（保持最少往返）  

     1. **第1次**：农夫带 **羊** → 右岸。  
        - 左：【农夫、狼、白菜】（安全）  
        - 右：【羊】  

     2. **第2次**：农夫 **单独** 返回左岸。  
        - 右：【羊】（安全）  
        - 左：【农夫、狼、白菜】  

     3. **第3次**：农夫带 **狼** → 右岸。  
        - 左：【白菜】（安全）  
        - 右：【羊、狼】 → **不安全**，所以在把狼放下之前必须把 **羊** 先调回左岸。  

     4. **第4次**：农夫带 **羊** 返回左岸。  
        - 右：【狼】（安全）  
        - 左：【白菜、羊、农夫]  

     5. **第5次**：农夫带 **白菜** → 右岸。  
        - 左：【羊】（安全）  
        - 右：【狼、白菜】（安全，因为没有羊）  

     6. **第6次**：农夫 **单独** 返回左岸。  
        - 右：【狼、白菜】（安全）  
        - 左：【羊、农夫]  

     7. **第7次**：农夫带 **羊** → 右岸。  
        - 左：空  
        - 右：【狼、白菜、羊】 → 此时所有物品都在右岸，且 **没有** “狼+羊” 或 “羊+白菜” 单独在一起的情况，因为农夫在场。

   - 这条路径共 **7 个单程**（即 4 次往返 + 最后一次单向）。  

6. **证明最优性**  
   - 要把 **羊** 从左岸运走，必须先把它带到右岸（第1次），然后在任何一次把 **狼** 或 **白菜** 运到右岸之前，必须把 **羊** 重新调回左岸，否则会出现非法组合。  
   - 因此，**羊** 必须被搬运 **至少两次**（一次去右岸、一次回左岸），而 **狼** 与 **白菜** 各只需要一次运送。  
   - 加上农夫每次单独返回或带其他物品的往返，最少的行程安排正是上面列出的 **7 步**。  
   - 任何比 7 步更少的方案都会导致在某一步中出现非法的动物组合，从而违背题目条件。  

**结论**：最少需要 **7 个单程**（即 4 次往返 + 最后一次单向）才能把农夫、狼、羊、白菜全部安全地渡过河。

**最终答案**  
7
