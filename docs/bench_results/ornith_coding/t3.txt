用户要求我修复一个binary_search函数，保持函数签名不变。让我分析这个函数的bug。

当前代码：
```python
def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo < hi:
        mid = (lo + hi) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid
        else:
            hi = mid
    return -1
```

问题：
1. 当 arr[mid] < target 时，lo = mid，这是正确的
2. 当 arr[mid] > target 时，hi = mid，这也是正确的
3. 循环条件是 lo < hi，当 lo == hi 时退出

让我检查边界情况：
- 如果 lo == hi，循环结束，返回 -1
- 但如果目标元素在 lo == hi 的位置呢？比如 arr = [5], target = 5，lo = 0, hi = 0，循环不执行，返回 -1，但应该返回 0

所以有两个问题：
1. 当 lo == hi 时，没有检查 arr[lo] == target 的情况
2. 循环条件 lo < hi 可能漏掉一些情况

让我修复：

```python
def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```
