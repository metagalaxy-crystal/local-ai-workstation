我们可以通过分析已知条件，逐步推导五人的名次顺序。

**已知条件：**
1. A 在 B 之前到达（A < B）
2. C 在 D 之后、E 之前到达（D < C < E）
3. B 在 D 之前到达（B < D）
4. E 不是第一名

**推理过程：**

**第一步：整合相对顺序**
根据条件 1、2、3，我们可以将 A、B、D、C、E 这五个人的相对位置串联起来：
- 由条件 1：A < B
- 由条件 3：B < D
- 由条件 2：D < C < E

将上述不等式链连接起来，得到：
**A < B < D < C < E**

这意味着，如果仅考虑这五个人的相对顺序，A 是最前的，E 是最后的。

**第二步：检查“E 不是第一名”这一条件**
目前的顺序是 A, B, D, C, E。
在这个顺序中，E 是最后一名（第5名），显然满足“E 不是第一名”的条件。

**第三步：确认是否有其他可能性**
让我们重新审视是否所有条件都被严格满足，以及是否有其他排列方式。
- 条件 1 (A < B)：满足。
- 条件 2 (D < C < E)：满足。
- 条件 3 (B < D)：满足。
- 条件 4 (E ≠ 1st)：满足。

由于这五个人的相对顺序已经被条件 1、2、3 完全锁定为 A -> B -> D -> C -> E，且这个顺序本身不违反条件 4，因此这就是唯一的解。

**验证：**
1. **A 在 B 之前**：是的，A 第1，B 第2。
2. **C 在 D 之后、E 之前**：是的，D 第3，C 第4，E 第5。
3. **B 在 D 之前**：是的，B 第2，D 第3。
4. **E 不是第一名**：是的，E 是第五名。

**最终名次（从先到后）：**
1. A
2. B
3. D
4. C
5. E
