这段代码的核心考点在于 Python 中**默认参数（default argument）的求值时机**。

### 推理过程

1.  **默认参数的特性**：
    在 Python 中，函数的默认参数值是在**函数定义时**（即 `def` 语句执行时）计算并创建的，而不是在每次函数调用时重新创建。这意味着，如果默认参数是一个可变对象（如列表 `[]`、字典 `{}` 等），该对象在函数的整个生命周期中是**唯一**的实例。

2.  **第一次调用 `f()`**：
    *   调用 `f()` 时，没有传入参数 `a`，因此使用默认参数。
    *   此时，`a` 指向函数定义时创建的那个空列表对象（假设其内存地址为 `L1`）。
    *   `len(a)` 为 0。
    *   `a.append(0)` 将 `0` 追加到列表 `L1` 中。
    *   列表 `L1` 变为 `[0]`。
    *   返回 `[0]`。
    *   **第一行输出：`[0]`**

3.  **第二次调用 `f()`**：
    *   再次调用 `f()`，仍然没有传入参数 `a`。
    *   **关键点**：`a` 仍然指向同一个默认列表对象 `L1`（即上一次调用后变为 `[0]` 的那个列表）。
    *   `len(a)` 为 1（因为列表里有一个元素 `0`）。
    *   `a.append(1)` 将 `1` 追加到列表 `L1` 中。
    *   列表 `L1` 变为 `[0, 1]`。
    *   返回 `[0, 1]`。
    *   **第二行输出：`[0, 1]`**

4.  **第三次调用 `f([7])`**：
    *   调用 `f([7])` 时，显式传入了参数 `a = [7]`。
    *   此时，`a` 指向的是新创建的列表 `[7]`，**而不是**默认的列表 `L1`。默认参数 `L1` 不受影响。
    *   `len(a)` 为 1。
    *   `a.append(1)` 将 `1` 追加到当前传入的列表 `[7]` 中。
    *   当前列表变为 `[7, 1]`。
    *   返回 `[7, 1]`。
    *   **第三行输出：`[7, 1]`**

### 最终答案

```
[0]
[0, 1]
[7, 1]
```
