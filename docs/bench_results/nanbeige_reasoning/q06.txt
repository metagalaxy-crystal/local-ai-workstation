### 推理过程

首先，分析函数 `f` 的定义：
```python
def f(a=[]):
    a.append(len(a))
    return a
```
- **默认参数的陷阱**：在 Python 中，函数参数的**默认参数是可变对象**（此处为列表 `[]`），且**在函数定义时被创建并共享**。这意味着所有调用 `f` 且不显式传入 `a` 时，都会操作**同一个列表对象**。
- **`a.append(len(a))` 的行为**：每次调用函数时，将当前列表 `a` 的长度追加到 `a` 末尾，并返回更新后的 `a`。

接下来，逐行分析打印结果：

#### 第1行：`print(f())`
- 调用 `f()` 时，未传入参数，使用默认参数 `a=[]`。
- 由于是第一次调用（且默认列表初始为空），`len(a) = 0`，执行 `a.append(0)`，此时 `a = [0]`。
- 返回 `[0]`，打印输出：`[0]`

#### 第2行：`print(f())`
- **关键点**：第二次调用 `f()` 时，**仍使用同一个默认列表对象**（因默认参数是共享的）。
- 当前列表 `a` 已有元素 `[0]`，故 `len(a) = 1`，执行 `a.append(1)`，此时 `a = [0, 1]`。
- 返回 `[0, 1]`，打印输出：`[0, 1]`

#### 第3行：`print(f([7]))`
- 调用 `f([7])` 时，**显式传入新列表 `[7]`**，此列表与默认列表**无关**，是独立的副本。
- 当前传入的列表 `a = [7]`，长度 `len(a) = 1`，执行 `a.append(1)`，此时 `a = [7, 1]`。
- 返回 `[7, 1]`，打印输出：`[7, 1]`

#### 验证默认参数共享的影响
- 若忽略默认参数的共享特性，错误认为每次 `f()` 都创建新列表，则第2行会输出 `[1]`（仅追加当前长度），但实际因共享，第2行输出累积结果 `[0, 1]`。
- 第3行因显式传入新列表，不受前两次共享影响，输出独立结果。

---

### 最终答案
```
[0]
[0, 1]
[7, 1]
```
