### 推理过程

我们需要根据题目给出的条件，确定A、B、C、D、E五人赛跑的完整名次（从先到后）。以下逐步分析：

---

#### **条件梳理：**
1. **A 在 B 之前到达** → A < B（A的名次数字比B小）
2. **C 在 D 之后、E 之前到达** → D < C < E（D的名次 < C的名次 < E的名次）
3. **B 在 D 之前到达** → B < D（B的名次数字比D小）
4. **E 不是第一名** → 第1名 ≠ E

---

#### **逻辑推导：**

- 由条件2：D < C < E  
- 由条件3：B < D  
  → 合并得：**B < D < C < E**

- 由条件1：A < B  
  → 将A插入链中：  
  **A < B < D < C < E**

- 验证条件4：E 不是第一名  
  → 当前序列中，E是第5名，**满足“E不是第一名”**（第1名为A）。

---

#### **验证所有条件是否自洽：**
- A 在 B 前：✅ A=1, B=2
- C 在 D 后、E 前：✅ D=3, C=4, E=5 → D < C < E
- B 在 D 前：✅ B=2, D=3
- E 不是第一名：✅ E=5 ≠ 1

所有条件均被满足，且名次唯一确定。

---

### 最终答案
**从先到后的完整名次为：A、B、D、C、E**
